# Atık PNG görselleri

16 nesne için şeffaf arka planlı, fotoğraf gerçekçiliğinde üretilmiş PNG.
Bunlar gerçek nesnelerin kamerayla çekilmiş fotoğrafları değildir; yerleşik
image_gen aracıyla ürün fotoğrafı görünümünde üretilmiştir. Marka veya harici
görsel servisi kullanılmaz. Oyun internetsiz bu yerel dosyaları yükler.

Üretim komutları: `generation-prompts.json`.

Oyun ve kutu örnekleri aynı dosyaları `src/art.ts` üzerinden kullanır.
